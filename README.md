# 🍳 AI Recipe Generator

This is an AI-powered web application that helps users decide what to cook. Simply upload a photo of your available ingredients — the system will automatically detect the items, allow manual editing, and generate **three recipe suggestions** tailored to your preferences.

## 🔧 Project Overview

This project follows a decoupled front-end and back-end architecture:

- **Frontend**: Built with [Vue.js](https://vuejs.org/), responsible for user interaction and input. The interface is clean, responsive, and user-friendly.
- **Backend**: Developed with [Python](https://www.python.org/) and [Flask](https://flask.palletsprojects.com/). It integrates OpenAI’s API to identify ingredients and generate recipe suggestions.
- **Communication**: The frontend and backend communicate via Axios using HTTP requests.

## ✅ Features

- 📷 Upload a photo to automatically detect ingredients
- ✏️ Modify or add ingredients manually
- 📋 Generate **three** recipe suggestions based on selected items
- 🍱 Choose preferred cuisine styles (e.g., Chinese, German) for more personalized results
- 🌐 Clean separation between frontend and backend for scalability and maintainability
